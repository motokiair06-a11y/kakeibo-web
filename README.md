# 家計ノート（household-ledger）

サブスクリプション・収支・資産をまとめて管理するReact製の家計簿アプリです。

## 主な機能

### サブスク管理
- 初回支払い日・支払い周期（日/週/ヶ月/年を自由に組み合わせ）を登録し、支払日までのカウントダウンを表示
- 停止・再開（同一IDのまま状態を切り替えるため、無料体験の再登録を繰り返しても重複しません。停止中は支払い履歴に追加されません）
- **複製ボタン**で似たサブスクをすばやく追加
- **支払い方法**（カード名など）を記録し、サービス別・支払い方法別で集計を切り替え可能
- 名前の頭文字による色分けアバターでひと目でサービスを区別
- 支払日の指定日数前にリマインド表示
- **支払い履歴**：稼働中のサブスクは支払日が来ると自動的に実績として記録されます（手動削除も可能）
- **分析**：支払い履歴を「月間（今月）」または「任意の期間（初期値は直近1年間）」で集計し、ドーナツグラフで表示

### カレンダー
- 月間カレンダーにサブスクの支払い（実績・予定）と収入・支出を色分けして表示
- 日付を選ぶとその日の記録一覧と、収入・支出のクイック追加が可能

### 収支
- カテゴリ別に記録（支出:「買い物」、収入:「お小遣い」を含む）
- **編集機能**：金額・カテゴリ・日付・メモを後から修正可能
- **検索・絞り込み**：キーワード、収入/支出、カテゴリで一覧を絞り込み
- **カテゴリ別予算**：月ごとの上限を設定し、使用状況を進捗バーで表示（超過時は警告色）
- ホームから収入・支出をワンタップで追加できるクイック追加ボタン

### 資産
- 国内株式現物 / 米国株式現物 / 投資信託 / 預かり金等現金の4区分で評価額・評価損益を入力
- 保存するたびに履歴として記録され、評価額の推移を折れ線グラフで表示
- ホームの「自由に使えるお金」は収入 − 支出 − 実際に支払われたサブスク額（支払い履歴ベース）で計算し、株式・投資信託などの資産は含めません

### レポート
- 今月と先月を比較（収入・支出・サブスク・自由に使えるお金）
- 支出カテゴリ トップ5、サブスク支払い トップ5
- 資産評価額の先月末比

### 設定（ヘッダー右上の⚙️アイコン）
- **バックアップ/復元**：全データをJSONファイルとしてエクスポート／インポート
- **ダークモード**の切り替え

### PWA（ホーム画面に追加）
- `manifest.json` とService Workerに対応。スマホでサイトを開き「ホーム画面に追加」するとアプリのように起動でき、オフラインでも表示できます

## セットアップ

```bash
npm install
npm run dev
```

`http://localhost:5173` で開発サーバーが起動します。

## ビルド

```bash
npm run build
npm run preview
```

`dist/` に静的ファイルが出力されます。GitHub Pages・Netlify・Vercelなど任意の静的ホスティングにデプロイできます。

## データの保存について

入力したデータはブラウザの `localStorage` に保存されます。サーバーには送信されません。

- ブラウザやデバイスごとに保存されるため、別の端末やブラウザとは同期されません
- ブラウザのデータ消去（キャッシュクリア等）で消える場合があります
- **機種変更やブラウザの変更前には、設定画面（⚙️）から必ずJSONバックアップをエクスポートしてください**。エクスポートしたファイルは同じ画面からインポートして復元できます
- 複数端末で同期したい場合は、Supabase・Firebaseなどのバックエンドと接続する形に拡張してください

- React 18 + Vite

- lucide-react（アイコン）
